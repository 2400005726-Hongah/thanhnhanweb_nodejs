Cập nhật giao diện trang Địa điểm:
- Bỏ hoàn toàn chữ CẤP 1 / CẤP 2 / CẤP 3.
- Bố cục gọn hơn: khối trên cùng cho Tỉnh/Thành, bên dưới 2 cột Bộ lọc địa điểm và Địa điểm cụ thể.
- Danh sách có cuộn, header dính, nhìn gọn hơn khi dữ liệu dài.
- Dữ liệu hiển thị có sắp xếp theo thứ tự:
  + Bộ lọc: Tỉnh/Thành -> sortOrder -> tên.
  + Địa điểm: Tỉnh/Thành -> bộ lọc mặc định -> sortOrder -> tên.
- Giữ nguyên toàn bộ API/backend/database.
